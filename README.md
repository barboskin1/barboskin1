# Barboskin Chat

Простой чат с регистрацией через Firebase Auth и хранением сообщений в Firestore.

## Как запустить

1. Скачай проект и распакуй
2. Открой терминал и перейди в папку проекта
3. Запусти скрипт `start.bat` (для Windows) для установки зависимостей и запуска dev-сервера
4. Открой в браузере http://localhost:5173

## Что внутри

- React + Vite
- Firebase Auth для регистрации и входа
- Firestore для сообщений чата
- Простой UI с чатами и аутентификацией
